## Why this exists

The scope document ([`kaioken_v2/docs/studio-v0.1-scope.md:58-60`](../../kaioken_v2/docs/studio-v0.1-scope.md#L58-L60))
names the wiki pane *"the cheapest real value in the app because it reuses a base class rather than
building one"*.

While the knowledge graph explorer is deferred past v0.1 because it requires an entire custom node-link
rendering canvas, repository documentation generated by `kaioken wiki` already lives as a structured
hierarchy of Markdown files under `.kaioken/wiki/`. Theia provides `TreeWidget`, a battle-tested,
virtualised tree component with keyboard navigation, expansion toggles, and selection events.
Bolting `TreeWidget` onto the backend wiki reader provides immediate, high-value visual browsing of
the codebase knowledge base for near-zero development effort.

## What done looks like

- [ ] A dedicated Wiki pane opens in the left sidebar via `Ctrl+Alt+W` or the activity bar.
- [ ] The tree displays all generated chapters, modules, and sub-articles located in `.kaioken/wiki/`.
- [ ] If `.kaioken/wiki/` has not been generated yet, a clean empty-state card is rendered with an
      inline affordance: `"No wiki generated yet. Run 'kaioken wiki' to build documentation."`
- [ ] Clicking a document node opens the markdown file in a viewer with dual-font typography (sans-serif
      body prose at 15px/1.75 line-height, JetBrains Mono headings and code fences).
- [ ] Changes to wiki files on disk automatically refresh the tree structure without requiring an IDE restart.

## Steps

1. **Verify Backend Outline RPC:** Confirm `theia-extensions/kaioken/src/node/kaioken-service-impl.ts`
   reads `.kaioken/wiki/outline.yaml` (or scans `.kaioken/wiki/*.md`) and returns structured `WikiNode[]`.
2. **Subclass TreeWidget:**
   - In `kaioken-wiki-widget.tsx`, ensure `KaiokenWikiTreeWidget` implements `TreeWidget`.
   - Map `WikiNode` entries to Theia `CompositeTreeNode` and `SelectableTreeNode`.
   - Add file/folder icons and badge indicators for verified vs unverified documents.
3. **Handle Node Selection:**
   - On tree item double-click or enter, invoke Theia's `OpenerService.open(uri)` to display the
     document in the editor/preview area.
4. **Apply Design System Typography:**
   - In `src/browser/style/index.css`, configure wiki prose styling:
     - font-family: `Geist Variable`, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
     - font-size: 15px; line-height: 1.75;
     - Headings (`h1`–`h4`): `JetBrains Mono`, uppercase tracking, Kaioken orange accent border.
5. **Add Keybinding and Command:** Verify `Ctrl+Alt+W` toggles the wiki pane.

Manual checks:
1. Press `Ctrl+Alt+W` — Wiki view activates in the left sidebar.
2. In a repository with `.kaioken/wiki` generated (e.g. `kaioken_v2`), verify chapters appear with expandable hierarchy.
3. Click a chapter: markdown opens in editor pane with clean sans-serif typography and styled monospace code blocks.

## Traps

| Trap | Guard |
|---|---|
| Rebuilding a custom virtual tree component from scratch | Use `@theia/core/lib/browser/tree/tree-widget`. It handles selection, keyboard arrows, and scrolling natively. |
| Using monospace font for 2,000-word wiki articles | `studio-design-brief.md` §3 permits sans-serif (`Geist`) specifically for wiki prose bodies to maintain readability. |
| Crashing when `.kaioken/wiki` is missing | Catch filesystem errors gracefully and render an informational empty state with generation instructions. |
