## Why this exists

A developer tool is not a consumer mobile app. When software engineers run Kaioken in a commercial repository, the tool reads proprietary intellectual property, internal architecture designs, API structures, and sensitive business logic ([`kaioken_v2/apps/cli/src/main.ts:40-42`](file:///D:/project/ai_now_know/kaioken_v2/apps/cli/src/main.ts#L40-L42)).

When the user chooses to route inference through the hosted inference proxy ([`roadmap/money_print/b3-hosted-surface/01-what-gets-hosted.md`](01-what-gets-hosted.md), `b2/05`), **that proxy directly processes the user's source code**. 

In corporate software procurement, the security and privacy review is the primary gatekeeper. If the privacy policy is vague or copies generic marketing boilerplate, corporate infosec teams immediately reject the product. Furthermore, under European GDPR (Article 28) and California CCPA regulations, processing personal data or proprietary code on behalf of commercial entities legally mandates an executed **Data Processing Agreement (DPA)** with Standard Contractual Clauses (SCCs).

This enumeration is **engineering work as much as legal work**. The legal terms directly constrain what the proxy code in `b2/05` is permitted to log, buffer, or persist.

## The concrete privacy contract: what is seen, logged, and never stored

To satisfy corporate legal reviews, the Data Processing Agreement and Privacy Policy must enumerate data flows with engineering specificity:

| Data category | Concrete contents | Transmitted? | Logged / Retained? | Retention period | Architectural constraint on `b2/05` |
|---|---|---|---|---|---|
| **Customer Source Code & Prompts** | File contents, AST declarations, prompt instructions, generated cards/wikis | Yes, in-flight HTTPS stream through proxy to upstream LLM | **NEVER STORED.** In-flight proxy streaming only. Processed entirely in RAM. | **0 seconds.** Evaporates immediately upon connection close. | Proxy logging middleware must explicitly redact or omit `req.body` and `res.body`. Zero disk buffering. |
| **Model Completions** | Text generated by LLM (markdown chapters, card text, code suggestions) | Yes, streamed back from upstream LLM to client | **NEVER STORED.** | **0 seconds.** Streamed directly to client socket. | Never persisted in proxy database or cache. |
| **Accounting Metadata** | User ID, API Key hash, timestamp, upstream model name, input token count, output token count | Yes | **YES.** Retained in billing database for quota enforcement and invoicing reconciliation. | **90 days**, then aggregated into permanent monthly totals. | Required for billing dispute resolution (`b2/07`). |
| **Operational & Security Logs** | Client IP address, user-agent, request ID, HTTP response status, error codes | Yes | **YES.** Stored in temporary edge observability buffer. | **30 days** maximum, then automatically purged. | Used solely for DDoS mitigation, rate limiting, and incident investigation. |
| **Local Knowledge Files** | `.kaioken/scan.json`, `.kaioken/index.json`, `.kaioken/wiki/` | **NO.** | Stored strictly on user's local disk. | Governed by user's local filesystem. | Engine never syncs local files to Kaioken servers. |

## The three legal documents

### 1. Terms of Service (ToS)
- **License Grant:** Outlines rights to use the hosted proxy service and desktop/CLI builds.
- **Acceptable Use Policy (AUP):** Prohibits reverse engineering of the proxy, submitting malicious payloads intended to jailbreak upstream models, or launching DDoS attacks.
- **Payment & Cancellation:** Codifies the 14-day refund policy ([`roadmap/money_print/b3-hosted-surface/04-uptime-and-support-promise.md`](04-uptime-and-support-promise.md)).
- **Limitation of Liability & Warranty Disclaimer:** Explicitly states the service is provided "AS IS", capping total liability to the fees paid in the prior 12 months. Disclaims liability for AI hallucinations, syntactic errors in generated code, or missed security vulnerabilities.
- **Governing Law & Dispute Resolution:** Specifies the jurisdiction chosen in `b4/01`, with mandatory arbitration or small-claims exception.

### 2. Privacy Policy
- Discloses the minimal collection of billing metadata and security logs.
- Discloses third-party sub-processors (Stripe/Paddle for billing; Anthropic, OpenAI, AWS/Cloudflare for hosting and inference).
- Explicitly states that **user source code is never used to train foundational AI models**, and that upstream enterprise agreements with zero-data-retention (ZDR) apply.
- Outlines GDPR user rights: right to access, right to rectification, right to erasure of account records.

### 3. Data Processing Agreement (DPA)
- Standardized, downloadable, pre-signed DPA for enterprise customers.
- Designates the customer as the **Data Controller** and Kaioken's entity as the **Data Processor**.
- Incorporates EU Standard Contractual Clauses (SCCs) to permit legal transfer of data to US-based serverless and LLM infrastructure.
- Formal security commitments: TLS 1.3 in transit, AES-256 for token accounting credentials, vulnerability reporting procedures within 72 hours of verified data breach.

## Traps

| Trap | Guard |
|---|---|
| Logging request bodies to Sentry or Datadog during debugging | If an uncaught exception dumps `req.body` into error tracking, source code is leaked to a third-party SaaS. Sanitize all error payloads at the edge. |
| Claiming "end-to-end encrypted" inference | A proxy that unwraps HTTPS to inject API tokens is NOT end-to-end encrypted. Be scrupulously honest: use "encrypted in transit via TLS 1.3 with in-memory zero retention". |
| Accepting customer redlines on terms | A solo maintainer cannot afford to pay an attorney $1,500 to review every $50/month corporate customer's legal redlines. Standard terms only. |
